## Requirements for Device Support

For a device to be supported by VoidOS it needs:
- Unlockable bootloader
- Active AOSP / LineageOS device tree
- Treble support (Project Treble)
- Minimum 4GB RAM / 64GB storage recommended

---

## Request Your Device

Want your device supported? Open an issue with:
- Device name and model number
- Device codename
- Link to an existing AOSP/LineageOS device tree (if available)
