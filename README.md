# NakedOS
Privacy-First, De-Googled Mobile OS

## What is NakedOS?
Open source Android OS — No Google. No tracking. No compromise.

## Features
- No Google services
- MicroG support
- Aurora Store + F-Droid
- APK Sideloading
- PWA Support
