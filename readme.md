# VoidOS - Custom Privacy & Security Framework

> An experimental prototype focused on Android security research, SELinux policy analysis, network filtering, and privacy utilities.

## Project Structure & Scope
- **Privacy Utilities:** Custom scripts for telemetry/data stripping.
- **System Hardening:** Experiments with SELinux enforcement profiles and kernel-level network rules.
- **Status:** Active prototype / Research stage.
