# Contributing to VoidOS

Thanks for your interest in VoidOS! We welcome contributions from everyone.

## Ways to Contribute

- **Report bugs** — Open an issue with your device info and steps to reproduce
- **Suggest features** — Open a discussion or issue with your idea
- **Submit code** — Fork the repo, make your changes, open a pull request
- **Improve docs** — Fix typos, clarify steps, add examples
- **Test builds** — Flash builds on your device and report results

## Before You Start

- Check existing issues and PRs to avoid duplicates
- For big changes, open an issue first to discuss before coding

## Pull Request Guidelines

1. Fork the repo and create a new branch: `git checkout -b feature/your-feature`
2. Keep commits focused — one change per commit
3. Write clear commit messages: `[privacy] block new Firebase endpoint`
4. Test your changes before submitting
5. Reference related issues in your PR description: `Closes #42`

## Code Style

- **Python** — Follow PEP8, use descriptive variable names
- **Shell** — Add comments for non-obvious commands, use `set -e`
- **XML** — Indent with 4 spaces, add comments for removed blocks

## Reporting Issues

Please include:
- Device name and codename (e.g. Redmi Note 10 / `sunny`)
- Android version
- Steps to reproduce the bug
- Expected vs actual behavior
- Logs if available

## Community

Be respectful. VoidOS is built by people who care about privacy — keep discussions constructive and on-topic.
